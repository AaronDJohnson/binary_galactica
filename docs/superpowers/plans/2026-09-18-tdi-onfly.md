# TDI on the fly Implementation Plan

> **For agentic workers:** Use subagent-driven development with independently
> owned numerical modules and final integration review. User authorized building
> and making this backend mainline; proceed through implementation and checks.

**Goal:** Make sparse-time TDI response construction the default waveform engine.

**Architecture:** Form demodulated XYZ directly, interpolate complex response
through amplitude/phase with zero-safe local reconstruction, restore source
phase, and FFT. Keep the previous link-FFT engine behind explicit selection.

**Tech Stack:** Python, JAX float64, NumPy, pytest; independent C fixtures.

**Spec:** `docs/superpowers/specs/2026-09-18-tdi-onfly-design.md`

## Global Constraints

- Preserve preexisting uncommitted work; do not commit, merge or publish it.
- Python >=3.10, JAX >=0.4.30, NumPy >=1.24; no new runtime dependency.
- Preserve raw units, carrier layout, formats, parameter conventions and AD.
- `backend="onfly"` is the default; `backend="fourier"` is explicit legacy.
- `response_samples=512` initially; positive static integer at least four.
- GLASS frozen instantaneous geometry, actual arm lengths; no TDI-2 claim.

## Task 2: Zero-safe sparse complex interpolation

Files: new `src/binary_galactica/glass/interpolation.py`,
`tests/glass/test_interpolation.py`.

Interface: `interpolate_response(response_fn, knots, query,
max_refinements=8)` uses callback `(n_times,) -> (n_times,n_channels)` and returns
`query.shape + (n_channels,)`. Knots and query include only times within the
observation interval. Shared per-cell refined anchors use the worst channel.

- [x] Write and run failing tests for `z(t)=(t-r)*exp(1j*a*t)`, a tangent
  `(t-r)**2`, a near miss `(t-r)+1j*epsilon`, an identically zero channel and
  smooth rotating responses, including scale `1e-22` and normalized AD checks.
- [x] Implement JVP time derivatives, polar cubic Hermite interpolation,
  guarded Cartesian fallback and fixed-shape selected-cell refinement.
- [x] Confirm true callback refinement improves reconstruction and root motion
  participates in derivatives. Test query endpoints and exact sampled zeros.

## Execution record

- Baseline: 423 tests passed in 23.51 s on Python 3.11 / JAX 0.7.2.
- Environment: default Python's readline extension segfaults during pytest
  startup. Tests run with `sys.modules["readline"]=None` before importing pytest;
  this isolates the unrelated capture initialization failure.
- Initial checkout preserved at `/private/tmp/bg-onfly-before` for review.
- Mainline integration: 468 tests passed in 163.52 s on JAX 0.7.2 and
  NumPy 2.3.5. Two subsequently added tangent-Hessian and refinement-capacity
  regressions passed separately, bringing the collected suite to 470 tests.
- The independent direct-response corpus contains 12 pinned-C cases, spanning
  0.1/1/5/30 mHz, 7/8/9 parameters, four orientations, signed chirps and
  amplitudes 1 and 1e-22. Regeneration is byte-identical. The C reference uses
  analytic source/orbit evaluators in place of spline storage; its original
  large-carrier subtraction limits comparison precision at low frequency.
- All 102 standalone zero-prototype tests passed. Ruff lint (without cache),
  formatting, whitespace and the mypy public-consumer check passed.
- The quickstart passed in source and from an extracted wheel outside the
  checkout, including batching and a `(2,512,8)` native Jacobian. Physical/native
  relative difference was 3.387e-16. All 45 legacy/new C-reference and response
  tests passed against the wheel outside the checkout in 15.05 s.
- Version 0.3.0 sdist and wheel built; all 22 wheel Python modules match the
  source, NOTICE is included, and the sdist contains the new C provenance,
  fixtures, interpolation tests and benchmark record.
- `tools/performance/onfly.json` records four dense-response convergence cases
  at BW=2048. Maximum per-channel relative L2 error at 512 samples was 4.90e-6;
  at 1024 samples it was 3.14e-7. The coarse 128-sample 30 mHz case had 0.134
  error, so sparse-grid convergence is a caller responsibility.
- Warmed CPU native latency for the recorded quarter-year case was 2.28 ms
  (onfly) versus 0.390 ms (Fourier). This implementation does not establish a
  speedup over the legacy backend.
- Independent numerical and final benchmark/provenance review found no
  blocking issues. Clarified the old versus new C-reference tolerances and
  that the benchmark's first timing call may reuse earlier compilation.
- Confirmed numerical distinction: pinned spline and legacy Fourier C paths
  place directed links differently. Their finite-frequency spectra need not
  agree even for equal static arms; the normalization check explicitly reverses
  links in the old synthesis. This is documented rather than fitted away.
- Final minimum-dependency validation: all 470 tests passed on Python 3.11.8,
  JAX/JAXlib 0.4.30, NumPy 1.24.0, SciPy 1.10.1 and ml-dtypes 0.2.0, including
  forward/reverse derivatives, Hessians and all public adapters. Python 3.10
  itself was not rerun locally for this migration; the CI matrix covers it.
- Strict Twine checks passed for both version 0.3.0 artifacts. All eight
  vendored C function hashes match the recorded provenance. Changes remain
  in the working checkout, preserving the preexisting work; no release was
  published and no branch integration was performed.

## Performance follow-up

- Profiled the reported slowdown. The initial interpolator gathered endpoint
  values and derivatives onto the FFT grid before computing each polynomial;
  optimized CPU code repeated response arithmetic inside those gathers.
- Moved Cartesian/amplitude/phase coefficient construction to the sparse
  cells, appended only selected refined-cell coefficients, and gathered one
  packed table before polynomial evaluation. The sampling, physical response,
  exact derivatives, zero guards and refinement budget remain the same.
- Independent inspection found no numerical or AD blocker. All 470 tests
  passed on JAX 0.7.2 in 186.12 s. All 47 focused interpolation/response/public
  on-fly tests also passed on minimum JAX 0.4.30 / NumPy 1.24.0 in 85.12 s.
- Refreshed `tools/performance/onfly.json` with 100 warmed calls and preserved
  the initial report as `onfly-initial.json`. Native latency fell from 2.28 ms
  to 1.63 ms; outer-JIT latency was 1.58 ms. The Fourier backend measured
  0.378 ms. Accuracy at all twelve convergence settings is unchanged to the
  reported precision. Separately compiled response-only and response-plus-time-
  derivative stages measured 0.140 ms and 0.536 ms.
- Remaining costs differ from GLASS's value-sampled natural cubic spline
  implementation: this path uses exact time derivatives, fixed 512-point
  sampling and source-only phase demodulation. GLASS also removes a reference
  spacecraft phase, so its smaller grid cannot be adopted without convergence
  validation. This follow-up reduces overhead; it does not establish a speedup
  over the Fourier backend.
